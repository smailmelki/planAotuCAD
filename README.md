# مخطط الغرف — PlanRebuild

تطبيق ويب تقدمي (PWA) لرسم المخططات الهندسية ثنائية الأبعاد، مع دعم التخزين المحلي للمشاريع وتصدير/استيراد JSON وDXF.

## التشغيل
افتح `index.html` في متصفح حديث. لتثبيت التطبيق كتطبيق PWA، استضفه عبر HTTPS أو خادم محلي يدعم Service Worker، ثم اختر «إضافة إلى الشاشة الرئيسية» من المتصفح.

## أدوات الرسم
- خط، جدار، مستطيل، دائرة، مثلث، رسم حر.
- ARC: اسحب من مركز القوس إلى نقطة النهاية. يبدأ القوس من الاتجاه الأفقي الموجب.
- ELLIPSE: اسحب لتحديد حدود الشكل البيضاوي.
- POLYGON: اختر عدد الأضلاع (3 إلى 32)، ثم اسحب من المركز إلى نصف القطر.
- POLYLINE: انقر لإضافة الرؤوس، ثم اضغط «إنهاء POLYLINE» أو انقر مرتين. النقر قرب الرأس الأول يغلق المسار كمضلع.
- أبواب، نوافذ، نصوص، أبعاد، سهم الشمال وأثاث.

## التحرير
حدد عنصرًا أو مجموعة، ثم استخدم «تدوير» لإدخال زاوية بالدرجات أو «تحجيم» لإدخال عامل التحجيم. العامل 2 يضاعف الحجم، و0.5 يصغّره إلى النصف. التدوير والتحجيم يتمان حول مركز التحديد.

## الإدخال الرقمي
تتوفر حقول الإدخال الرقمي للعناصر وأدوات الرسم التي تدعمها، وتختلف الحقول حسب نوع العنصر: الطول والزاوية للخطوط، العرض والارتفاع للمستطيل، نصف القطر للدائرة، أنصاف المحاور للبيضاوي، زوايا القوس، وعدد الأضلاع ونصف القطر للمضلع. كما يمكن تعديل آخر مقطع في متعدد الخطوط والرسم الحر، وحجم النص وسهم الشمال. لا يشمل الإدخال الرقمي المستقل أدوات الأبعاد أو وضع الأبواب والنوافذ أو الأثاث؛ تُستخدم هذه الأدوات بالطريقة المعتادة عبر اللوحة واللمس أو الفأرة. القيم المدعومة تُدخل وفق وحدة المشروع الحالية (متر أو سنتيمتر)، ويمكن الضغط على Enter أو زر «تطبيق» عند توفره.

## الملفات
من قائمة المشروع:
- **تصدير**: اختر JSON لحفظ المشروع مع طبقاته وخصائصه، أو DXF للتبادل مع برامج CAD.
- **استيراد**: اختر ملف JSON أو DXF ASCII، أو الصق محتوى الملف نصيًا.

JSON هو التنسيق الأنسب للاحتفاظ بخصائص التطبيق والطبقات. DXF يصدّر الكيانات الهندسية المدعومة؛ بعض العناصر المركبة مثل الأثاث والأبواب قد تتحول إلى خطوط/مسارات عند التصدير.

## ملاحظات تقنية
- القياسات الداخلية بالمتر، ويمكن تغيير وحدة العرض إلى السنتيمتر.
- بيانات المشاريع تحفظ محليًا في المتصفح.
- يدعم استيراد DXF ASCII والكيانات الشائعة التي يعالجها المحلل، وليس كل مواصفات DXF.

### الإدخال الرقمي المستقل (v8)
عند اختيار أداة رسم مدعومة تظهر لوحة إدخال مستقلة. يمكن كتابة إحداثيات النقاط دون استخدام اللوحة، أو اختيار النقاط باللمس/الفأرة. بعد تحديد النقطة الأولى تنتقل اللوحة تلقائياً إلى الخطوة التالية. تشمل الأدوات المدعومة الخطوط والمستطيلات والمثلثات والجدران، إضافة إلى الدائرة والقوس والبيضاوي والمضلع ومتعدد الخطوط والرسم الحر، وفق حقول كل أداة. لا يشمل هذا الإدخال المستقل أدوات الأبعاد أو الأبواب أو النوافذ أو الأثاث؛ ويمكن استخدام هذه الأدوات باللمس أو الفأرة.
